## 为什么有的咒语改名了

法术是**按声音**识别的。两个法术读音太近——比如"幻弹"和"魂灯"只差一个元音——识别器就可能
施错法术。2026-09 批次改掉了一批易混的中文触发词，把混淆对拉开。**旧词是刻意移除的**；
每个改名法术都保留或换上了更清晰的词面。

| 法术 | 旧词 | 新词 |
|---|---|---|
| Falsum（虚影弹） | ~~幻弹~~ | **虚影弹**（保留） |
| Vestibulum（火墙） | ~~火墙~~ | **燎墙** |
| Silva Voco（唤林） | ~~唤林~~ | **唤森** |
| Volatus（疾风步） | ~~疾风步~~ | **迅风步** |
| Aurae Levitas（轻风步） | ~~轻风步~~ | **踏云步** |
| Sagitta（圣光矢） | ~~圣光矢~~ | **圣光箭** |
| Lumen（圣光束） | ~~圣光~~（裸短别名） | **圣光束**（保留） |

改词随发版进 CHANGELOG 并提前公告。

## 命名规则速查表

每个法术名——内置或数据包自定义——都要过五条检查：

| # | 规则 | 白话版 |
|---|---|---|
| 1 | **读音拉开** | 任意两个法术整体读音必须明显不同——不能只差一个元音 |
| 2 | **禁踩混淆维** | 两个名字不得**只靠** n/l、前后鼻音（-n/-ng）、平翘舌（s/sh、z/zh、c/ch）、f/h 之一来区分——这些正是语音最容易听混的维 |
| 3 | **禁包含** | 短触发词不得出现在其它法术的咒文行里（比如有法术别名"圣光"，又有一句咒文"圣光矢初现"，短的那个就会被误触） |
| 4 | **系列词拉开** | 共头系列（"唤X"）尾音节必须全拉开；共尾系列（"X墙"）头音节必须全拉开 |
| 5 | **长度** | 中文触发词建议 **≥2 音节**——单音节在识别上结构性吃亏 |

数据包作者：自定义词面上线前先跑 lint：

```
python ipa/check_alias_distinctness.py --spells <你的法术目录>
```

exit code 0 = 全绿。（工具完整说明在仓库 `ipa/check_alias_distinctness.py`。）

## FAQ

**我的旧触发词不管用了。**
刻意的。改词直接移除旧别名（不留隐藏的旧词兼容）——请用上表新词，游戏内典籍/吟唱 HUD
显示的永远是当前词面。

**还能用别的叫法吗？**
大部分法术有多个别名（如虚影弹同时认它的英文名）。吟唱 HUD 末句和 `spell_catalog.json`
列出的都是有效词面。

**怎么念更稳？**
念**全名**；优先用 2-3 音节的中文或英文别名，别即兴缩略；别指望靠细微音差（-n/-ng、s/sh）
区分法术——命名规则已经把法术拉开了，你只管咬字清楚。

**我加的数据包法术会误触别的法术。**
多半是词面对内置法术违反了规则 1-4。改掉涉事别名，重跑上面的 lint。

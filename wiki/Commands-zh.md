# 命令

所有作弊/调试命令位于 **`/wizardreal`**（别名 **`/wr`**），需要 **权限等级 2**（OP / 服务器控制台）。法术 id 为带命名空间的形式，如 `wizardreal:ignis`；Tab 键可从注册表补全。

| 命令 | 说明 |
|---|---|
| `/wr learn <法术> [目标]` | 教会一个法术。目标默认为执行者；控制台必须显式指定 |
| `/wr unlearn <法术> [目标]` | 忘记一个法术——对 5 个默认法术同样生效（以"已遗忘"记录；重新学习即清除） |
| `/wr cast <法术> [置信度]` | 以自己身份强制施法：无需法杖、无需学习，但法力（创造模式跳过）与冷却照常。`置信度`（0..1，默认 1.0）可在不开口的情况下测试阈值 |
| `/wr spells [过滤词]` | 列出已注册法术：名称、id、法力、冷却、是否需学习、是否已掌握 |
| `/wr spellinfo <法术>` | 完整定义导出：学派、源流、法力/冷却、学习标记、阈值、触发词、咏唱句子、效果列表 |
| `/wr known [目标]` | 列出目标已掌握的法术 |
| `/wr mana get\|set\|reset [目标] [数值]` | 查看/操纵法力（set/reset 会同步 HUD） |
| `/wr cooldown clear all [目标]` · `/wr cooldown clear <法术> [目标]` · `/wr cooldown set <法术> <秒> [目标]` | 冷却在任何施法路径下都不会被跳过，连发测试请用本命令清除/设置 |
| `/wr sync [目标]` | 强制重发法力/冷却同步 + 法术目录（排查 HUD/目录不同步） |
| `/wr state save` | 立即写入 `wizardreal_player_magic.nbt`（否则每 5 分钟自动保存） |
| `/wr state dump [目标]` | 原始状态导出：法力、已掌握、已遗忘、生效中的冷却 |

## 备注

- `learn`/`unlearn` 会立即向目标发布法术目录（HUD/图鉴的"已学习"标记无需重进生效），并强制存盘一次；
- 在**服务器控制台**执行面向玩家的命令必须显式给目标，例如 `/wr learn wizardreal:explosion Dev`；
- `cast` 只能由玩家执行——施法需要位置与视线向量，控制台无意义。

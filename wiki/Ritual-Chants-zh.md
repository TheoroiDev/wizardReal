# 仪式吟唱

> [← 返回首页](Home-zh.md) · 上一篇：[法术一览](Spells-zh) · 下一篇：[排障与 FAQ](Troubleshooting-FAQ-zh)

法术库中的每个法术都是仪式施法（见[法术一览](Spells-zh)）：触发词让你**进入吟唱状态**，随后必须逐句念完整段咒语，法术才会施放。吟唱时准星右侧会出现**吟唱 HUD**。

## 咏唱流程

1. **触发**：说出仪式法术的触发词（如 "explosion" / "爆裂"）——进入吟唱；
2. **逐句咏唱**：念出 HUD 上高亮（`►`）的那一句。识别命中后该句变绿（`✓`），下一句变为当前句；
3. **完成**：最后一句念完（通常是触发词，个别中文变体使用译名），法术立即施放。

## 规则细节

| 规则 | 说明 |
|---|---|
| **首句锁变体** | 每个法术有多种咒语变体（英/中/日，大型仪式每种语言还有多套）；你念的第一句决定本次用哪个变体，之后必须一路念完同一变体 |
| **念错重试** | 念错不会重来——**重复当前句**即可，已完成的句子进度保留 |
| **宽限窗 1.2 秒** | 刚完成一句后的 1.2 秒内识别尾音不报错（避免上一句的余音误判为错句） |
| **超时：每句 10 秒** | 连续 10 秒 × 咒文行数没有新的有效语句，吟唱自动取消（服主可改为固定上限） |
| **完成锁定 3 秒 / 取消锁定 1.2 秒** | 吟唱结束后的短时间内忽略后续语音（最后一句通常等于触发词，识别器会连发多条结果，避免瞬间重新触发） |
| **门禁前置校验** | 学习门槛、手持法杖、法杖起源与冷却都在**第一句被接受之前**校验——动作栏会给出具体原因；空法力不再作废念完的咏唱，施法按当前法力降档到可负担的阶梯 |
| **左键取消** | 吟唱中（按住右键时）点**左键**即可取消（不消耗法力） |

## 吟唱 HUD 图例

```
Explosion · 爆裂  42%    ← 法术名（金色）+ 你的熟练度
✓ 以漆黑遮蔽苍穹          ← 已完成（绿色 + 删除线）
► 唤醒绯红之雷            ← 当前句（青色高亮；上方显示拼音注音）
   以废墟之名封印          ← 未到（暗灰）
   解除一切矗立之物
   爆裂！                 ← 末句通常是触发词
✗ 重复本句                ← 念错时红字闪烁提示
```

**非吟唱状态**下，被拒的语句也会有回应（显示数秒后淡出）：

- 「✦ 咒文消散在风中」——服务器听到了语音，但没有任何法术过阈值；
- 「✦ 你听见了似是而非的低语……最接近：……」——你说的接近某个法术的触发词，HUD 会报出它的名字。

## 提示

- **显示语言跟随游戏语言**：游戏设为简体中文时 HUD 显示中文咒语行（识别按别名/音素匹配，与显示语言无关——用英文客户端也能念中文咒语，只要该变体已锁定）；
- 中文咒语每句都配了**拼音别名**、日文配了**罗马音**，整句与 IPA 引擎都能识别；
- 吟唱时**当前咒文行上方会显示注音**（拼音/罗马音）——照着念即可跟上进度（可在[配置](Configuration-zh)关闭或扩大范围）；
- 吟唱中的所有语音都只喂给当前仪式（触发词也不会中途开启新吟唱）；
- 法力与冷却在**完成的一刻**才结算——中途取消不消耗；
- **评分与共鸣（wizardReal#43）**：每完成一句都会打分（完美 ≥ 0.95 · 优秀 ≥ 0.85 · 及格 = 成功线 0.70）。**完美**咏唱触发**共鸣**：本次施法威力 +10%。评分永不改变成败，也绝不加熟练度——熟练度跟成功走、分数跟表现走；
- **练习模式**（`/wrpractice <法术>`）：零法力、零冷却、无实际效果的排练场——严档评分，HUD 随你的朗读**逐词高亮**，每完成一次练习熟练度 +1%（每日有上限；实机施法全额 +2%）。`/wrpractice stop` 退出。
